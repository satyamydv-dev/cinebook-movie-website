# CINEBOOK 🎬

CINEBOOK is a movie booking website created as a web development project.

## Features
- Home page
- Movies page
- Movie details
- Booking page

## Technologies Used
- HTML5
- CSS3

## About the Project
This project was built to practice website structure, styling, navigation, and forms.
